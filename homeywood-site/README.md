# Homey Wood

Dipecah dari homeywood-all-in-one.html. Desain (CSS) & logic tidak diubah.

    index.html        -> otomatis membuka pages/home.html

Buka index.html (atau pages/home.html) dengan klik dua kali. Tidak perlu server.
